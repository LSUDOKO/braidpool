# braidpool

Braidpool - a scalable peer to peer bitcoin mining pool with support for hashrate futures. 

## Commands

- build: `cargo build`
- test: `cargo test`

## Layout

- `braidpool-primitives/`
- `dashboard/`
- `docs/`
- `node/`
- `tests/`

## Rules

- Run `cargo test` before you say a change is done.
- Never commit secrets or `.env` files.
